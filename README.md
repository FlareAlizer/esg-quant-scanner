# ESG Quant Scanner

Скоринг активов, который совмещает портфельную теорию с качественным
ESG-анализом через LLM. Каждая бумага получает балл 0–10 по фреймворку PARKS,
из оценённого пула собирается портфель методом Марковица, результат проверяется
Монте-Карло.

## PARKS

| | | Источник | Метрики |
|---|---|---|---|
| **P** | Profitability | фундаментал | ROE, чистая маржа |
| **A** | Acceleration | фундаментал | рост выручки |
| **R** | Resilience | расчёт | волатильность, D/E, бета |
| **K** | Knowledge | LLM | качество управления, инновационность |
| **S** | Sustainability | LLM | ESG-профиль минус штраф за скандалы |

Метрики нормируются по отраслевым коридорам (`sector_config.py`), а не по
единой абсолютной шкале: ROE 15% — сильный результат для ритейла и средний для
софтверной компании.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt
cp .env.example .env                                 # вписать ключи
python backend/main.py
```

Параметры задаются флагами:

```bash
python backend/main.py --tickers MSFT NVDA V JPM ISRG \
                       --target-return 0.16 --max-weight 0.20 \
                       --years 10 --simulations 50000
```

Фронтенд:

```bash
cd frontend && npm install && cp .env.example .env && npm run dev
```

## Структура

```
backend/
  main.py                 CLI и оркестрация
  config.py               настройки, бутстрап TLS
  data_fetcher.py         Yahoo Finance, кэш цен
  llm_analyzer.py         веб-поиск и извлечение метрик
  company_scorer.py       PARKS
  sector_config.py        отраслевые коридоры
  risk_calculator.py      ковариация, ожидаемые доходности
  portfolio_optimizer.py  SLSQP, два режима
  monte_carlo.py          GBM-симуляция
  black_litterman.py      альтернативный движок: BL + GQV
  visualizer.py           графики
frontend/                 React 19 + TypeScript + Vite
```

## Заметки по реализации

Волатильность и ковариация считаются численно, а не запрашиваются у модели —
там, где есть точная формула, LLM не даёт преимущества. Модель отвечает только
за то, что плохо парсится: фундаментал ADR и ETF, репутационные риски.

Пропущенная метрика исключается из среднего, а не заменяется нулём. Иначе балл
мерил бы качество парсинга, а не качество компании.

Ковариация считается на лог-доходностях (они аддитивны во времени), перед
передачей в оптимизатор выполняется обратный перевод через `expm1`.

Оптимизатор проверяет выполнимость границ до запуска солвера: минимум 20% на
10 активов даёт сумму 200%, и такую задачу лучше отклонить с внятной ошибкой,
чем получить «не сошлось». Если лестница послаблений всё же сработала,
фактические границы возвращаются рядом с заказанными.

На Windows с кириллическим именем пользователя libcurl не может открыть
сертификаты certifi и каждый запрос падает с curl error 77. `config.ensure_ca_bundle()`
подставляет тот же файл по ASCII-пути через короткое 8.3-имя. Проверка TLS при
этом не отключается.

## Ограничения

Данные из веб-поиска не проходят аудит, модель может ошибиться в цифре — для
реальных решений метрики нужно сверять с отчётностью эмитента. Историческая
доходность как оценка будущей это известная слабость Марковица; на этот случай
в репозитории лежит альтернатива на Black-Litterman. Монте-Карло предполагает
логнормальность и постоянную волатильность, реальные хвосты толще.

Учебный проект. Не является инвестиционной рекомендацией.
